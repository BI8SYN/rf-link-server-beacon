# 开源首版交付计划

目标：管理员能为已有服务器增加广播，也能用官方 SAS 与 EMQX 新建服务器。保留已有身份和单 data 目录，提供 Docker 与 systemd 广播入口。

1. 保留个人运维记录到 Git 忽略的本地 data 目录；公开文档不包含实际申请、凭据、主机或负责人资料。
2. 对齐 SAS 官方参数和镜像，增加独立服务器 Compose、两个公开信任根和认证回调；身份未配置即拒绝启动，SAS 不对外开放端口。
3. 完善 setup → 人工审核 → wait → sas-command → 服务器启动 → 广播的中文教程。现有服务器复用 SAS 配置代码，无需迁移 Broker。
4. 更新公开 Go module、许可证、贡献说明与离线 CI；用临时身份验证参数生成、认证拒绝及 Compose 生命周期。
5. 运行 Go 测试、vet、脚本和 Compose 检查，审核发布文件。使用 BI8SYN 作者及提交者身份形成公开初始版本，推送指定 main。

不执行真实 APRS 测试，不修改现有生产服务，不发布镜像，不操作生产 CA。原生 systemd 与官方设备实测边界须如实保留。
