# Docker 完整栈自动部署

新建服务器填写一份 .env 并执行 docker compose up -d。预构建镜像负责申请、等候发布、验证并领取身份、配置 SAS、验证 MQTT 认证、开放入口和广播。原生完整栈在 Docker 验收后实施。

1. 使用独立管理模式和持久卷保存申请、进度、SAS 配置及 Dashboard 密码，继续使用已有身份和发报防重规则。
2. EMQX 仅在容器网络监听。Beacon 对外代理在同一次 EMQX 启动、SAS 已加载对应配置且实际 MQTT 探测走完认证回调后才转发。更换启动代次或 SAS 配置时重新检查。
3. 日志记录申请编号、审核阶段、重试时间、认证和发报结果。status 读取原子快照，不竞争身份状态锁。
4. Go 测试模拟审核、身份领取、认证故障及 APRS 回传。隔离 Compose 测试使用实际 SAS、EMQX 和临时密钥，验证发布前后以及重启期间的入口行为。
5. CI 构建 amd64/arm64 镜像，版本发布时推送 GHCR。教程覆盖配置、日志、status、Dashboard 密码读取和升级。
